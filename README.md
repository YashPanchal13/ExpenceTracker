# FinTrack Pro — Expense Tracker

A secure, full-featured personal finance tracker built with Python/Flask.

## Features
- 🔐 Secure authentication (hashed passwords)
- 💰 Income & expense tracking with categories
- 📊 Dashboard with charts and analytics
- 📅 Weekly & monthly reports
- 💳 Month opening/closing balance tracking
- 🚀 Ready to deploy on Render

## Deploy on Render (Free)

1. Push this folder to a GitHub repo
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect your GitHub repo
4. Render auto-detects `render.yaml` — just click **Deploy**
5. A persistent disk is created for the SQLite database

## Local Development

```bash
pip install -r requirements.txt
python -c "from app import init_db; init_db()"
python app.py
```
Visit http://localhost:5000

## Environment Variables (set in Render dashboard)
- `SECRET_KEY` — auto-generated by Render
- `DB_PATH` — path to SQLite file (default: /var/data/expense_tracker.db)

## Security Notes
- Passwords are hashed with Werkzeug's PBKDF2-SHA256
- Sessions are server-side signed cookies
- Each user only sees their own data
- SQL injection protected via parameterized queries
